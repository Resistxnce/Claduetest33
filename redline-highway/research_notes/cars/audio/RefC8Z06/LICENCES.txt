Licence notes
- CC BY: credit the author, the title, the licence and a link wherever the sound is used.
- CC BY-SA: anything made from the file must also be released under CC BY-SA. That is awkward
  for sounds inside a Roblox game, so use file 2 only as a listening and spectrum reference.
- "Licence review pending" means Commons has not yet confirmed the YouTube Creative Commons
  licence. Check the file page before relying on it.
- Commons notes that YouTube's CC licence moved from 3.0 to 4.0 on 1 Aug 2025, and the change
  was not retroactive.
- None of these files is an LT6. Treat them as character references only (an even per-bank pulse
  train and a high-rpm shriek), not as the car's own sound.
