# Ref720S audio: licence and attribution notes

Two freely licensed recordings of the McLaren 720S (M840T twin-turbo flat-plane V8) exist on Wikimedia Commons.
**Both cars have aftermarket exhausts, so neither is the stock sound.** Both files are the audio tracks of YouTube videos
that their owners published under CC BY. Commons marks both licences as "not yet reviewed" by its reviewers, so check the
file pages before using either in the game.

**Download status (2026-11-13).** Wikimedia's file server answered every request with HTTP 429 ("too many requests"); other
agents were downloading at the same time. A polite retry script was left running. If the `.opus` files are not in this
folder, fetch them from the URLs above. Nothing was downloaded from YouTube.

**Using CC BY 3.0 material.** Credit the author and link the licence (<https://creativecommons.org/licenses/by/3.0/>), and
say if the audio was changed, for example "Engine audio derived from 'McLaren 720S with Fi Exhaust' by FiExhaust,
CC BY 3.0, edited". Roblox audio uploads also need to pass moderation, and the credit should go in the game's credits.

**Not freely licensed (for reference only).** The Sonniss "McLaren 720S Spider SSG 2019" library is a commercial, royalty-free
sound pack and is not a CC licence: <https://sonniss.com/sound-effects/mclaren-720s-spider-ssg-2019/>.
